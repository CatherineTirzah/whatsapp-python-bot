# WhatsApp Automation Bot using Python

This project sends scheduled WhatsApp messages using Python using the
`pywhatkit` library.

## Features
- Send WhatsApp messages at a scheduled time
- Uses WhatsApp Web automation
- Simple command-line interface

## Requirements
- Python 3.x
- pywhatkit
- WhatsApp Web logged in browser

## How to Run
```bash
pip install -r requirements.txt
python main.py
